# GEC Website — نسخة مستقلة (Self-Contained)

**كل ملف HTML في هذا المجلد يحتوي كل شيء بداخله** — الـ CSS والـ JavaScript والشعار كلها مضمّنة.

## ✅ لماذا هذه النسخة تعمل 100%؟

- **لا ملفات خارجية** — كل صفحة ملف HTML واحد مستقل
- **لا يحتاج سيرفر** — افتح أي ملف مباشرة بالمتصفح وسيعمل
- **مضمون الرفع** — لن تنكسر المسارات النسبية

## 🚀 طرق الرفع

### الطريقة 1: Netlify Drop (الأسهل - 30 ثانية)
1. افتح: https://app.netlify.com/drop
2. اسحب **المجلد كامل** (gec_standalone) إلى الصفحة
3. رابط مباشر للموقع في ثوانٍ

### الطريقة 2: فتح مباشر بدون استضافة
1. افتح ملف `en/index.html` أو `ar/index.html` بأي متصفح
2. الموقع يعمل فوراً بدون إنترنت

### الطريقة 3: cPanel / FTP
1. ارفع محتويات `gec_standalone/` إلى `public_html/`
2. جاهز

## ⚠️ مهم

لو تحتاج تحدّث الألوان أو الأسلوب:
- التعديل داخل `<style>` في كل ملف HTML
- يجب تحديث جميع الـ 12 ملف
- (هذا الأسعر مقارنة بالنسخة العادية، لكنها مضمونة الشغل)

## 🔒 دخول الموظفين (`/crm/`)

صفحة متابعة المنشآت الصناعية للموظفين: **https://geckuw.com/crm/** (رابط «دخول الموظفين» في أسفل كل صفحة).

- `crm/` — واجهة الصفحة (HTML/CSS/JS).
- `api/crm/` — الخادم: تسجيل الدخول، البيانات، تسجيل المكالمات، المستخدمون. `api/_lib/` ملفات مشتركة.
- قاعدة البيانات: Neon Postgres (مشروع `industrial-directory-tracker`، قاعدة `gec`). رابط الاتصال في متغير البيئة
  `DATABASE_URL` في إعدادات مشروع Vercel، وليس في المستودع.
- دليل المنشآت (569 منشأة) محفوظ في جدول `directory` داخل قاعدة البيانات، وليس في هذا المستودع لأنه عام.
- `/crm/api/*` يُوجَّه داخلياً إلى `/api/crm/*` (انظر `vercel.json`)، والدوال تعمل في فرانكفورت (`fra1`) بجانب قاعدة البيانات.

## بطاقات الموظفين
صفحة إدارة البطاقات للمدير: **https://geckuw.com/crm/cards/** (تظهر روابطها في شريط CRM وقائمة المستخدم للمدير فقط).
كل بطاقة لها رابط عام برمز QR: `https://geckuw.com/card/?id=<المعرّف>`.

- `crm/cards/` — إضافة الموظف، تعديل بياناته، إظهار/إخفاء البطاقة، تحميل QR، وطباعة بطاقة CR80 طولية (54×85.6 مم) بوجهين.
- `card/` — البطاقة الرقمية العامة الطولية: الشعار في الوسط، الصورة، الاسم، المسمى، القسم، الرقم الوظيفي، الجوال/واتساب/البريد، الموقع الإلكتروني، اللوكيشن، حسابات X وإنستغرام ولينكدإن وسناب شات وتيك توك وفيسبوك، حفظ جهة الاتصال، والمشاركة.
- لكل بطاقة خيار «إظهار الصورة الشخصية»؛ عند إخفائه تختفي دائرة الصورة بالكامل من البطاقة الرقمية والطباعة مع بقاء الصورة محفوظة في الإدارة.
- الموقع الإلكتروني واللوكيشن ورابط الخريطة وإنستغرام ولينكدإن تُعرض بقيم الشركة الافتراضية إذا تُركت فارغة، ويمكن تخصيصها لكل موظف عند الحاجة.
- `api/crm/employees.js` — إدارة البطاقات (تتطلب جلسة مدير).
- `api/card.js` — القراءة العامة؛ لا يعيد البطاقات المخفية ولا الحقول التي أُخفيها المدير.
- الجدول `employees` يُنشأ تلقائياً مع بقية الجداول عند أول طلب. الصور تُقص وتُضغط في المتصفح وتُحفظ داخل الصف (حد أقصى ~380 كيلوبايت).
- `vendor/qrcode.min.js` — مكتبة QR محلية (MIT) حتى تعمل البطاقة والطباعة بدون CDN.
