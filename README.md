# GEC Website — نسخة مستقلة (Self-Contained)

**كل ملف HTML في هذا المجلد يحتوي كل شيء بداخله** — الـ CSS والـ JavaScript والشعار كلها مضمّنة.

## ✅ لماذا هذه النسخة تعمل 100%؟

- **لا ملفات خارجية** — كل صفحة ملف HTML واحد مستقل
- **لا يحتاج سيرفر** — افتح أي ملف مباشرة بالمتصفح وسيعمل
- **مضمون الرفع** — لن تنكسر المسارات النسبية

## 📁 الهيكل

```

```

## 🚀 طرق الرفع

### الطريقة 1: Netlify Drop (الأسهل - 30 ثانية)
1. افتح: https://app.netlify.com/drop
2. اسحب **المجلد كامل** (gec_standalone) إلى الصفحة
3. رابط مباشر للموقع في ثوانٍ

### الطريقة 2: فتح مباشر بدون استضافة
1. افتح ملف `en/index.html` أو `ar/index.html` بأي متصفح
2. الموقع يعمل فوراً بدون إنترنت

### الطريقة 3: cPanel / FTP
1. ارفع محتويات `gec_standalone/` إلى `public_html/`
2. جاهز

## ⚠️ مهم

لو تحتاج تحدّث الألوان أو الأسلوب:
- التعديل داخل `<style>` في كل ملف HTML
- يجب تحديث جميع الـ 12 ملف
- (هذا الأسعر مقارنة بالنسخة العادية، لكنها مضمونة الشغل)
